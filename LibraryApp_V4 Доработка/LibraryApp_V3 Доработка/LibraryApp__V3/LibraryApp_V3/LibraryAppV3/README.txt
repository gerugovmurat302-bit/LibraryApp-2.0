LibraryApp - информационная система «Библиотека вуза» (Windows Forms, C#, .NET 8, MySQL)

1. Установите MySQL Server 8.0+ и Visual Studio 2022 (нагрузка «Разработка классических приложений .NET»).
2. Выполните скрипт library_db.sql (MySQL Workbench: File -> Open SQL Script -> Execute).
3. Откройте LibraryApp.csproj в Visual Studio. Пакеты NuGet восстановятся автоматически.
4. В App.config укажите пароль пользователя root вашего MySQL (вместо ВАШ_ПАРОЛЬ).
5. Запустите проект (F5).

Тестовые учётные записи:
  admin / Admin#2026          - администратор
  librarian1 / Lib#2026       - сотрудник
  reader01 / Reader#2026      - ученик

Регистрация: Ученик - без кода; Сотрудник - код STAFF-2026; Администратор - код ADMIN-2026
(коды меняются в Security.cs: StaffCode и AdminCode).

Права ролей:
                                   Ученик   Сотрудник   Администратор
  Каталог, бронирование              да        да          да
  Личный кабинет (свои данные)       да        -           -
  Читатели: просмотр/добав./измен.   -         да          да
  Читатели: удаление                 -         -           да
  Выдача и возврат                   -         да          да
  Бронирования (все)                 -         да          да
  Штрафы: принять оплату             -         да          да
  Штрафы: списать                    -         -           да
  Издания и экземпляры (фонд)        -         -           да
  Сотрудники и пользователи          -         -           да
